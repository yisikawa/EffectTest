## 2. ffxitool5 の解析（`docs/ANALYSIS-ffxitool5-2026-11-13.md`）
- PE32/x86・非パック・D3D8・固定ベース 0x400000・PDB 名 Palladium.pdb
- ID→DAT 解決式: パック値 `rom<<16 | hi<<7 | lo`
- チャンク規則 `(hdr>>7 & 0x7FFFF)*16`（AltanaView の `>>3 & 0x7FFFF0` と同値）
- main の `+0x20/+0x24/+0x28` = 3 ストリーム、`+0x2C` = 長さ
- 描画ステート: 加算(SRCALPHA+ONE) / COLOROP=MODULATE4X(RGB×4) / CULL NONE / ZWRITE 0
- キー補間: 0..1 正規化・末尾 `(0,0)` 終端マーカー・線形
- サイズ: VM Scale そのもの（0x21 実寸は掛けない）
- ブレンド: フラグ bit2 で 加算/α
- **部分実装**: `prn`/`kr1x`/`kr3x` は `Doesn''t work`。動くのは `gr00`/`rn00`/`kr10` のみ

## 3. アプリへの反映（`feature/schedule`）
- `--moveint on|off`（Move 積分。Cure の直線が解消）
- VM#1 `0x3B`（Move 回転）、`0x3A`/`0x3D`/`0x3E`/`0x40`、VM#2 `0x29`/`0x2B`
- `--keymode norm`（ffxitool5 方式）＋ 終端マーカー除外で α がデータ由来に
- `--emitrate 0`（データ駆動: 1 周期に 1 個）→ **Cure II〜V の飽和が解消**
- 大判粒子（Scale>=0.5）の単一化
- **`--ffxi on|off`**: 上記を一括適用
- **`--only <gen>`**: 要素単位の比較用
- リファクタ: 誤仮説の `--size quadscale` を削除
