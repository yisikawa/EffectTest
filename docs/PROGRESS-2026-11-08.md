## 3. 実装した内容（EffectTest）

### 3.1 List ブラウザ
- `ModelTest\List`（115 ファイル）＋`AltanaView\List\Effect`（26 CSV）を `EffectTest\List` に統合
- 3 段 UI: **グループ**（NPC ROM1〜9 / Effect カテゴリ）→ **項目**（ダブルクリックで確定）→ **Action**（NPC の `0x07`）
- ID 解決: `11/17` → `ROM\11\17.DAT`、`1-131-6` → `ROM\131\6.DAT`、ROM 別は `index.csv` 3 列目を使用
- **文字コード**: BOM/UTF-8 妥当性で UTF-8 / Shift-JIS を自動判定 → UTF-16 化し、コントロールは Unicode(W) 版

### 3.2 Effect 再生（AltanaView 準拠）
- タイムライン（`main`、+0x80 起点）＋ジェネレータ（`0x05`、0x90 ヘッダ）＋2 段 VM
- 出力（位置/スケール/色）を加算合成ビルボードで描画
- 開始オフセットの自動判定（Effect `main`=+0x80 / NPC `0x07`=+0x50）

### 3.3 NPC Action 解析
- NPC DAT の `0x07` を列挙し、命令列（op/len/delay/param/name）を解析・ログ出力
- 参照名は **先頭 3 文字一致**で `0x2B` を解決（ModelTest の `SetMotion3FromList` と同一仕様）

### 3.4 ベースエフェクト（`0/0` = `syst`）
- 起動時に `ROM\0\0.DAT` を読み、gen/tex/timeline を索引（**描画はしない**）
- 実測: 1,105 チャンク / gen 320 / tex 61 / timeline 132 / **load_ms = 3**（61 枚の DXT3 SRV 生成込み）

### 3.5 起動時の挙動（本日の指示を反映）
- **起動時は何も表示しない**（背景のみ。座標軸も既定 OFF、`X` で切替）
- **表示のトリガーは List の項目選択**。自動表示したい場合のみ `--auto`

### 3.6 検証モード（ヘッドレス）
`--list` / `--base` / `--action "<dat>" [name]` / `--selftest "<dat>"` / `--shot "<dat>" <png>`

## 4. 解析で確定した仕様（AltanaView 0.6.2）

| 項目 | 内容 |
|---|---|
| エフェクト DAT | `main`(0x07)=タイムライン / `0x05`=ジェネレータ（0x90 ヘッダ） / `0x19` / `0x1F` / `0x20` / `0x21` / `0x3D` |
| タイムライン命令 | `[op][len][delay:u16][param:u16][name:4B]`、`op 0x02`=生成 / `0x2A`=RGBA / `0x3D/0x3E`=条件ブロック |
| 時間 | **固定 60 fps**、`delay` 加算方式（`delay=0` は同フレーム連続実行） |
| VM#1 / VM#2 | `FUN_0040e650`（目標値評価）/ `FUN_0040f4b0`（時間積分、ループ折返し） |
| サブオブジェクト | `0x108 + dest*4`（pos 0x80 / move 0x8C / scale 0x98 / color 0xA4 / elapsed 0xEC / t01 0xF0 / prev 0xF4） |
| NPC DAT | `0x07`=Action（39 個）/ `0x2B`=モーション（18）/ `0x3D`=変種（19） |
| モデル | テクスチャは**同一 DAT の `0x20`**（DXT3 実測）、モーション解決は**3 文字前方一致** |

|---|---|---|
