# 検証: 粒子を「直線状」ではなく「円周上」に配置する（2026-11-12）

- 指示: 「動画から見て直線状ではなく円周上に配置する方向で検証してください」
- ブランチ: `feature/schedule`
- 対象: VM#1 の `0x06`（旧: 球面ランダム）と `0x1F`（旧: 未実装）

---

## 1. 仮説と根拠

| 項目 | 内容 |
|---|---|
| 仮説 | 粒子の初期位置は**円周（楕円）上**に並ぶ（半径は全粒子で一定、位相だけ乱数） |
| 根拠 1 | `docs/ANALYSIS-AltanaView-Draw.md` §10.6c: `0x06`/`0x07`/`0x1F` = 「**円運動＋乱数位相**」（`thunk_0042e1b8` 系） |
| 根拠 2 | `0x1F` の引数 11 個のうち先頭 2 個が楕円半径らしい値（0.1〜0.5） |
| 根拠 3 | 実測: 旧実装では `0x1F` が no-op のため粒子の横方向の広がりが **r ≈ 0.008**（＝1 点に重なる＝画像では直線） |

実データの引数（`11\17` / `11\18` / `12\43`）:

| op | len | 引数（浮動小数） | 解釈 |
|---|---|---|---|
| `0x06` | 4 | `(0.6,0)` `(0.2,0.1)` `(0.2,0.2)` `(0.3,0.2)` `(0.2,0.6)` `(0,0.5)` `(0.4,0)` | 楕円半径 `(rX, rY)` |
| `0x1F` | 12 | `(0.2,0.2,1,1,1,0,0,-0.8,1.5,0,0)` ほか | 先頭 2 個が楕円半径。`arg7`（**-0.4〜-0.8**）と `arg8`（0.8〜1.5）は未確定 |

## 2. 実装

| ファイル | 変更 |
|---|---|
| `EffectVm.cpp` | `PlaceOnRing()` を追加（XY 平面の楕円、位相のみ乱数）。`0x06` を円周配置に（`--ring off` で旧・球面）。`0x1F` を新規実装（円周配置） |
| `Effect.h` | `EffectSetRing` / `EffectRing` / `EffectSetRingScale` / `EffectSetRingDist` |
| `App.cpp` | `--ring on\|off`、`--ringradius xy\|dist`、`--ringscale N` |
| `tools/RingStats.ps1` | 画像が「中詰まり（直線・塊）」か「中抜け（円周・リング）」かを数値化 |

判定指標（`RingStats.ps1`）:
- `hollow` = 中央帯の平均輝度 / 外周帯の平均輝度。**< 1.0 で中抜け（リング状）**、> 1.0 で中詰まり。
- `aspect` = 非背景の外接矩形の幅/高さ（参照の柱は 0.40 前後が目標）。

## 3. 検証結果

### 3.1 配置そのもの（`--trace` の生成直後粒子、`elapsed < 0.06 s`）

| DAT / gen | op（半径） | `--ring off` 半径 / CV | `--ring on` 半径 / CV |
|---|---|---|---|
| `11\17` `g002` | `0x1F` (0.2, 0.2) | 0.0084 / **0.707**（1 点に重なる） | **0.1897 / 0.158** |
| `11\17` `g003` | `0x06` (0.2, 0.2) | 0.2361 / 0.350（球面でばらつく） | **0.1963 / 0.130** |

- `--ring on` の半径 **0.19 ≈ データの 0.2**（＝引数が半径であることを実測で確認）。
- CV（半径のばらつき）が **0.71 → 0.16** に低下＝「円周上に整列」。
- 旧実装の `0x1F` は半径 0.008（ほぼ 1 点）で、**粒子が直線に重なって見えていた**ことの直接証拠。

### 3.2 画像（`--frames 90` / 既定）

| DAT | `--ring off` | `--ring on`（新既定） |
|---|---|---|
| `11\17` | 5,023 / 129, aspect 0.789, hollow 2.851 | **5,310 / 115**, aspect 0.960, hollow **2.145** |
| `11\18` | 3,053 / 465, aspect 0.827, hollow 7.520 | **3,488 / 462**, aspect 0.917, hollow **6.582** |
| `11\22` | 962 / 298, aspect 0.447, hollow 1.206 | 962 / 298（`0x06`/`0x1F` を持たない）, hollow 1.203 |
| `12\43` | 3,615 / 244, aspect 1.891, hollow 1.333 | **3,500 / 342**, aspect 1.808, hollow **1.253** |

→ 円周配置により **hollow が低下**（中詰まりが緩む）が、**1.0 未満（＝明確なリング）にはならない**。

### 3.3 なぜ画像でリングに見えないか（半径の倍率スイープ）

データの半径（0.1〜0.7 m）に対し、ビルボードの寸法は 2〜4 m（`--size meter`）。
円周がビルボードに埋もれるため、倍率を振って確認した:

| `--ringscale` | `11\17` hollow / aspect | `11\18` hollow / aspect |
|---|---|---|
| ×1（データ値） | 2.145 / 0.960 | 6.582 / 0.917 |
| ×2 | 1.477 / 1.172 | 3.607 / 1.027 |
| ×4 | **0.954** / 1.553 | 1.731 / 1.128 |
| ×8 | 0.782 / 2.282 | 1.564 / 1.069 |

→ **×4 で初めて hollow < 1（リング状）**になるが、縦横比が 1.55 まで広がる（参照の「柱」0.40 から遠ざかる）。

### 3.4 `arg7` を半径にした場合（`--ringradius dist`）

`0x1F` の `arg7` は -0.4〜-0.8 で generator ごとに一定。半径として妥当かの A/B:

| DAT | `xy`（arg0/arg1, ×1） | `dist`（\|arg7\|, ×1） | `dist` ×2 |
|---|---|---|---|
| `11\17` | hollow 2.145 / aspect 0.960 | 2.528 / 0.960 | 2.043 / 1.172 |
| `11\18` | hollow 6.582 / aspect 0.917 | **3.941 / 0.924** | 2.244 / 0.979 |

→ `11\18` では `dist` が **縦横比を保ったまま hollow を 6.58 → 3.94 に改善**。
`arg7` が半径である可能性が高いが、負値の意味（初期の後退量？）が未確定のため**既定は `xy`** とした。

## 4. 結論と残課題

1. 指示どおり「**円周上配置**」を実装し、**配置が円周であることを実測で確認**した（半径 = 引数、CV 0.71→0.16）。
2. ただし現状の既定（データ値そのまま）では、**ビルボードが半径より大きいため画像上のリングは弱い**（hollow 2.1/6.6）。
   見た目でリングを出すには `--ringscale 4` 前後が必要だが、縦横比が 1.5 超になる。
3. 残課題:
   - `0x1F` の `arg7`（-0.4〜-0.8）/ `arg8`（0.8〜1.5）の意味確定（半径・速度・後退量のどれか）。
   - 参照動画のフレーム（`frames/v_*.png` 等）を再取得し、`hollow` と縦横比の**目標値**を決める。
   - リングの面（現在は XY＝進行方向に垂直）。`0x21` クワッドの向きとの関係を確認。
